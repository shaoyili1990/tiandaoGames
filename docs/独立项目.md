## 一、项目背景与目标

### 1.1 现存问题

SillyTavern 是目前最强的 AI 角色扮演前端，但存在以下致命问题：

| 问题 | 影响 |
|------|------|
| **部署困难** | 需要 Node.js、Python、数据库等多项配置，90% 非技术用户卡在入门第一步 |
| **上手门槛高** | 需要手动创建世界书、人物卡、事件卡，填写大量格式文档 |
| **时间戳等待** | 角色只能被动等待玩家输入，无法自主演化 |
| **多元化不足** | 缺乏自动演化、分支叙事、玩家注入融合等高级功能 |

### 1.2 项目目标

**核心目标**：将天道系统打造为「零门槛即开即用的 AI 角色扮演自主演化系统」

**具体指标**：
1. 用户只需配置一个 AI API KEY，5 分钟内完成部署
2. 输入「都市」「玄幻」「科幻」等关键词，AI 自动生成全套模板
3. 上传小说，AI 自动拆解为角色卡+世界书+事件卡
4. 角色具备自主演化能力，支持玩家中途注入想法
5. 完美兼容 SillyTavern 人物卡、世界书格式

### 1.3 核心价值

```
技术小白 ──────────────────────────────► 资深玩家
   │                                        │
   │  "部署太难了"                           │  "我想让角色自主演化"
   │  "不知道怎么创建世界"                    │  "我想上传自己的小说"
   │  "格式太复杂"                           │  "我要深度定制"
   │                                        │
   └──────────── 天道独立版 ─────────────────┘
              "即开即用，AI 帮我启动第一步"
```

## 三、核心模块设计

### 3.1 启动器 (Launcher)

**职责**：一键初始化环境、检测依赖、启动服务

**核心流程**：
```
用户执行启动命令
    ↓
检测 Python 版本 (≥3.9)
    ↓
检测 API KEY 配置
    ↓
安装/更新依赖 (pip install -r requirements.txt)
    ↓
初始化数据目录
    ↓
启动 Gradio Web UI
    ↓
显示访问地址
```

**关键代码设计**：
```python
class TiandaoLauncher:
    def __init__(self, api_key: str = None):
        self.api_key = api_key or os.getenv("TIANDAO_API_KEY")
        self.config = ConfigLoader.load()

    def check_environment(self) -> dict:
        """检测环境，返回问题列表"""
        issues = []
        if not self.check_python_version():
            issues.append("Python 3.9+ required")
        if not self.api_key:
            issues.append("API KEY not configured")
        if not self.check_dependencies():
            issues.append("Missing dependencies")
        return {"ready": len(issues) == 0, "issues": issues}

    def install_dependencies(self):
        """安装依赖"""
        subprocess.run([
            sys.executable, "-m", "pip", "install",
            "-r", "requirements.txt"
        ], check=True)

    def start(self, mode: str = "web"):
        """启动服务"""
        if mode == "web":
            from src.web_app import create_app
            app = create_app(self.config, self.api_key)
            app.launch()
        elif mode == "cli":
            from src.cli import create_cli
            cli = create_cli(self.config, self.api_key)
            cli()
```

### 3.2 世界生成器 (World Generator)

**职责**：根据用户选择的类型，自动生成完整的世界书、人物卡、事件卡模板

**生成类型**：
| 类型 | 说明 | 包含内容 |
|------|------|----------|
| `urban` | 都市 | 现代城市、社会关系、职场/校园 |
| `fantasy` | 玄幻 | 仙侠、修炼体系、宗门势力 |
| `sci-fi` | 科幻 | 未来世界、科技设定、外星文明 |
| `romance` | 言情 | 情感纠葛、多角关系 |
| `horror` | 悬疑 | 推理、惊悚、神秘事件 |
| `xianxia` | 仙侠 | 修仙、古风、飞升体系 |

**核心流程**：
```
用户选择世界类型
    ↓
加载类型模板 + AI 生成提示词
    ↓
调用 AI API 生成：
  - 世界观概述 (500字)
  - 地理/社会设定 (1000字)
  - 势力/组织设定 (800字)
  - 规则/法则设定 (500字)
    ↓
生成默认人物卡 (主角x1 + 配角x3)
    ↓
生成初始事件卡 (3-5个)
    ↓
打包为 SillyTavern 兼容格式
    ↓
展示预览 + 允许用户编辑
    ↓
导出到数据目录
```

### 3.3 小说拆解器 (Novel Parser)

**职责**：上传小说文本，AI 自动拆解为角色卡+世界书+事件卡

**拆解流程**：
```
用户上传小说 (txt/epub/mobi)
    ↓
文本预处理 (编码检测、章节分割)
    ↓
提取关键信息：
  - 主要角色 (名字、性格、关系)
  - 世界设定 (地点、势力、规则)
  - 重要事件 (情节点)
    ↓
生成结构化数据：
  - 角色卡列表 (JSON)
  - 世界书内容 (Markdown)
  - 事件卡列表 (JSON)
    ↓
用户选择模式：
  模式A：角色视角游戏
    - 选择主角或其他角色
    - 从特定时间点开始
  模式B：剧情推演模式
    - 提供大纲/细纲
    - AI + 天道自动演化
    ↓
导出为 SillyTavern 兼容格式
```

**两种游戏模式**：

**模式 A：角色视角游戏**
```
用户选择角色 → 设定时间点 → 开始对话
    ↓
角色响应 + 自主演化
    ↓
玩家可中途注入想法
    ↓
继续演化循环
```

**模式 B：剧情推演模式**
```
用户提供大纲/细纲
    ↓
AI 分析小说内容 + 用户大纲
    ↓
天道系统推演剧情发展
    ↓
每阶段输出：
  - 剧情发展概述
  - 角色心理变化
  - 关键抉择点
    ↓
用户可：
  - 确认继续 → 演化下一阶段
  - 注入想法 → 融入推演
  - 中断自写 → 续接继续
```

### 3.4 演化层 (Evolution Layer)

**核心模块**：

| 模块 | 文件 | 职责 |
|------|------|------|
| 演化生成器 | `evolution/engine.py` | 基于心理档案生成多轮行为链 |
| 注入融合器 | `evolution/injection.py` | 解析玩家注入并融合到演化链 |
| 场景适配器 | `evolution/scene.py` | 单人/双人/群像场景适配 |
| 演化追踪器 | `evolution/tracker.py` | 演化链持久化与回溯 |
| 输出格式化 | `evolution/formatter.py` | 生成可读输出格式 |

**演化状态机**：
```
IDLE → AWAITING_INPUT → EVOLVING ↔ PAUSED → OUTPUT → ARCHIVED → IDLE
                              ↑
                        玩家注入时暂停
```

**注入类型处理**：
| 类型 | 触发关键词 | 处理方式 |
|------|------------|----------|
| Strong | "我决定"、"我选择" | 重置演化链，以玩家内容为新起点 |
| Medium | "突然"、"原来" | 中断演化，融合新信息后继续 |
| Weak | 仅内心想法 | 追加到当前行为，不打断演化 |

**行为生成算法**：
```
1. 确定当前心理状态 (stable/vulnerable/aggressive/chaotic)
2. 激活最高优先级本能
3. 构建表层动机
4. 推导深层动机
5. 选择行为类型 (internal/external/verbal/mixed)
6. 生成行为描述
7. 心理锚定验证 (MBTI/Y值/记忆/动机一致性)
8. 输出并记录
```

### 3.5 引擎层 (tiandaosystem_max 复用)

直接复用 `tiandaosystem_max_1.0` 核心模块：

| 模块 | 功能 |
|------|------|
| `psychology.py` | Y值心理引擎：击穿/补偿/回弹三大机制 |
| `mbti.py` | MBTI权重系统：16种人格的欲望/情绪权重 |
| `memory.py` | 记忆系统：5种记忆类型、权重衰减 |
| `motivation.py` | 动机链：五层动机递进分析 |
| `author.py` | 作者约束：冲突解析、群像模拟 |
| `profile.py` | 角色画像：统一接口 |

### 5.3 一键安装脚本设计

```batch
@echo off
chcp 65001 >nul
echo ========================================
echo     天道系统独立版 - 安装程序
echo ========================================
echo.

:: 检查 Python
python --version >nul 2>&1
if errorlevel 1 (
    echo [错误] 未检测到 Python，请先安装 Python 3.9+
    echo 下载地址: https://www.python.org/downloads/
    pause
    exit /b 1
)

:: 获取 API KEY
echo 请输入你的 AI API KEY：
echo (支持 Claude / OpenAI 格式)
set /p API_KEY=
echo.

:: 保存配置
echo API_KEY=%API_KEY% > config.env
echo.

:: 安装依赖
echo [1/3] 正在安装依赖...
python -m pip install -r requirements.txt
if errorlevel 1 (
    echo [错误] 依赖安装失败
    pause
    exit /b 1
)

:: 创建数据目录
echo [2/3] 初始化数据目录...
mkdir data\worlds 2>nul
mkdir data\characters 2>nul
mkdir data\sessions 2>nul

:: 完成
echo [3/3] 安装完成！
echo.
echo ========================================
echo     安装成功！
echo ========================================
echo.
echo 下一步：
echo   1. 双击运行 quickstart.bat
echo   2. 浏览器打开 http://localhost:7860
echo.
pause
```

## 八、技术风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| AI API 调用失败 | 系统无法生成内容 | 提供离线模板作为备选 |
| 长文本处理 | 小说太长导致解析失败 | 分段处理 + 进度显示 |
| 内存溢出 | 多角色演化时内存不足 | 定期清理 + 限制会话数 |
| 格式不兼容 | 导出的卡牌在 SillyTavern 显示异常 | 提供格式验证 + 手动修复指南 |
| API KEY 安全 | 用户 KEY 泄露 | 仅本地存储，不上传服务器 |

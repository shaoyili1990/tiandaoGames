## 三、系统核心哲学

### 3.1 天道公式原文

```
系统 = 先天本能（水） + 后天参数（容器） + 实时计算（势）
行为输出 = 水的物理流动（无善恶，只有力学）

天道 = 损有余而补不足
包含：
1. 盈满则亏
2. 过犹不及
3. 动态流转
4. 并列共担
```

### 3.2 Y值本质定义（公式原文）

```
Y = 人物「主观意识凝练强度」
是人物精神内核的稳定指数
不代表：情绪、血量、好感度

Y值体现：
1. 执行力：Y越高，主观意识越坚定，执行力越强
2. 影响力：Y越高，气场越强，越能带动、碾压Y值更低的人
3. 被影响力：Y越低，意识越涣散，越容易被诱骗、洗脑、操控、击穿
```

## 五、演化层设计深度解析

sillytaventavern_tiandao_skill的演化层是整个系统的**最顶层应用**，其设计如下：

### 5.1 演化链状态机（设计文档原文）

```
IDLE → AWAITING_INPUT → EVOLVING ↔ PAUSED → OUTPUT → ARCHIVED → IDLE
                              ↑
                        玩家注入时暂停
```

### 5.2 注入类型处理策略

| 注入类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| **Strong** | 出现"我决定"、"我选择"等 | 重置演化链，以玩家内容为新起点 |
| **Medium** | 出现"突然"、"原来"等 | 中断演化，融合新信息后继续 |
| **Weak** | 仅内心想法 | 追加到当前行为，不打断演化 |

### 5.3 心理锚定验证（4项）

```
行为生成
    ↓
心理锚定验证（4项检查）
    ├── MBTI一致性？
    ├── Y值合理性？
    ├── 记忆一致性？
    └── 动机链一致性？
    ↓ 通过
输出行为
```

## 八、核心结论

**三者确实是同一系统的三个层次：**

1. **公式层**（tiandao/天道公式/）= 理论根基，数学基础
2. **引擎层**（tiandaosystem_max_1.0）= 公式的Python实现，模块化可调用
3. **接口层**（sillytavern_new_system_tiaodao_1.0）= SillyTavern集成，当前未调用引擎
4. **演化层**（sillytaventavern_tiandao_skill）= 顶层应用设计，纯文档需工程化

**当前问题：**
- 接口层和引擎层**已断连**
- 演化层**完全未工程化**
- 公式层有完整计算流程但代码未完全实现

**理想状态：**
```
演化层（工程化后）→ 调用 → 引擎层 → 基于 → 公式层
     ↑                                       │
     └───────────── SillyTavern UI ┘
```

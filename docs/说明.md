

项目1：tiandaosystem\_max\_1.0

定位：纯Python核心库（独立运行，无需其他依赖），用于角色心理建模与动机分析。



核心功能

模块	功能说明

psychology	Y值情绪调节系统 — 跟踪角色情绪波动（0-100），计算反弹、补偿、触发阈值

mbti	16种MBTI人格的权重数据 + 行为倾向分析

memory	分层记忆系统（短期/长期/情感/创伤），支持关键词搜索和权重衰减

motivation	动机链生成：本能层→表层→深层→核心层→灵魂层，五层动机递进分析

author	作者约束系统：冲突解析、群像场景生成、多角色互动模拟

profile	统一角色画像，聚合以上所有子系统

安装与使用

bash

\# 方式1：从zip解压

unzip tiandaosystem\_max\_1.0.zip

cd tiandaosystem\_max\_1.0

pip install -e .



\# 方式2：直接引用

export PYTHONPATH=/path/to/tiandaosystem\_max\_1.0

CLI使用（命令行）：



bash

tiandao y-value calculate 75      # 计算Y值状态

tiandao y-value rebound 30 80      # 计算情绪反弹

tiandao mbti show INFP             # 查看MBTI类型

tiandao mbti compare ENFP ISTJ    # 对比两种人格

tiandao memory add "重要事件" --personality ENFP  # 添加记忆

tiandao memory search "事件"       # 搜索记忆

tiandao motivation --add "自我实现" 0.9  # 添加动机

tiandao author validate name       # 验证作者名

tiandao run-demo                   # 运行演示

Python API使用：



python

from tiandao import create\_profile, save\_profile



\# 创建角色

profile = create\_profile("Alice", mbti\_type="ENFP", base\_y=70)

profile.psychology.update\_y(85)         # 情绪更新

profile.memory.add\_memory("第一次冒险", tags=\["action"])

profile.motivation.add\_link("成就感", 0.9)



\# 保存/加载

save\_profile(profile, "alice.json")

print(profile.get\_summary())

项目2：sillytavern\_new\_system\_tiaodao 1.0

定位：将天道系统集成到 SillyTavern（AI聊天前端）的插件包，包含JS插件 + Flask后端。



核心功能

组件	功能说明

tiandao\_plugin.js	SillyTavern客户端插件 — 加载时自动初始化，监听聊天事件，调用后端API

server.py	Flask API网关 — 接收请求、路由分发、缓存管理

psychology\_api.py	人格分析引擎 — MBTI检测、大五人格分析、情绪状态计算、核心恐惧/动机识别

character\_card\_parser.py	角色卡解析器 — 支持SillyTavern V1/V2格式，提取描述、性格、语音模式

message\_formatter.py	消息格式化 — 情感标注、上下文整理、提示词注入

安装步骤

bash

\# 1. 启动后端

cd backend

pip install -r requirements.txt

cp .env.example .env

python server.py              # 开发模式

\# 或: gunicorn -w 4 -b 0.0.0.0:5000 server:app  # 生产模式



\# 2. 安装SillyTavern插件

\# 复制 tiandao\_plugin.js 到 SillyTavern的插件目录

cp sillytavern\_plugin/tiandao\_plugin.js /你的/SillyTavern路径/scripts/extensions/plugins/



\# 3. 在SillyTavern界面启用

\# 设置 > 扩展 > 插件 > Tiandao System > 启用

API端点

bash

\# 健康检查

curl http://localhost:5000/api/health



\# 解析角色卡

curl -X POST http://localhost:5000/api/characters \\

&#x20; -H "Content-Type: application/json" \\

&#x20; -d '{"name":"角色名","description":"角色描述..."}'



\# 人格分析

curl -X POST http://localhost:5000/api/psychology/analyze \\

&#x20; -H "Content-Type: application/json" \\

&#x20; -d '{"name":"角色","description":"喜欢冒险和创造..."}'



\# 情绪状态计算

curl -X POST http://localhost:5000/api/psychology/emotional-state \\

&#x20; -d '{"messages":\[{"role":"user","content":"..."}]}'



\# 格式化对话

curl -X POST http://localhost:5000/api/format-conversation \\

&#x20; -d '{"messages":\[{"role":"user","content":"hi"}]}'

两者的关系

项目1 (tiandaosystem\_max\_1.0)          项目2 (sillytavern插件包)

┌─────────────────────┐               ┌──────────────────────────┐

│ 纯Python核心库       │               │ JS插件 + Flask后端        │

│ 独立运行             │──功能逻辑──→   │ 集成到SillyTavern         │

│ 命令行+API           │               │ Web界面配置               │

└─────────────────────┘               └──────────────────────────┘

项目2的后端API（psychology\_api.py）在功能逻辑上与项目1的模块对应，但做了适配Web API的封装。项目1适合开发者自己构建应用，项目2适合直接接入SillyTavern使用。

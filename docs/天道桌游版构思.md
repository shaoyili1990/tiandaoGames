> 项目代号：Tiandao_TRPG
> 版本：0.1 (构思中)
> 日期：2026-04-28
> 状态：构思讨论阶段

## 一、项目背景与灵感

### 1.1 现有系统的问题

| 系统 | 模式 | 局限性 |
|------|------|--------|
| SillyTavern | 1:1 玩家↔角色 | 本质是"跟AI聊天"，没有DM角色 |
| 传统TRPG | 多人围桌 + 1 DM | 依赖真人DM，时间精力有限 |
| AI Dungeon | 1:1 玩家↔AI | 单人冒险，缺乏社交氛围 |
| 我的世界/Minecraft | 多人沙盒 | 没有叙事引导，纯自由探索 |

### 1.2 灵感来源

```
传统桌游 (D&D等)
├── 1个DM (主持人)
│   ├── 设计世界观
│   ├── 控制NPC
│   ├── 触发事件
│   └── 裁判裁决
│
└── N个玩家
    ├── 扮演自己创建的角色
    ├── 互动、探索、战斗
    └── 推动剧情

问题：DM是稀缺资源，一个好DM可遇不可求
    时间精力有限，无法随时开团

我的构思：
用天道系统替代真人DM
让多个玩家同时在线，共享一个AI DM
每个玩家扮演自己创建的角色
天道负责：搭建舞台、触发事件、控制NPC、裁决结果
```

### 1.3 核心定位

**口号**：
```
赛博跑团 - 老天爷当DM，多位玩家同屏共创
```

**一句话说明**：
> 多个玩家连接到同一个天道DM服务器，每个人扮演自己创建的角色。天道系统负责搭建世界观、触发事件、控制NPC，玩家自由互动、探索、战斗，经历由天道精心设计（基于天道规则）的剧情。

### 2.2 角色定位对比

| 角色 | SillyTavern | 天道桌游版 |
|------|-------------|-----------|
| **天道系统** | 无 | **DM** - 主持全局，触发事件，控制NPC |
| **玩家** | 扮演AI设定的角色 | **扮演自己创建的角色** |
| **AI角色** | 玩家操控的对象 | **NPC** - 由天道控制 |
| **世界观** | 预设或用户创建 | **由天道生成**，玩家探索 |

### 2.3 核心差异

| 维度 | 传统TRPG | SillyTavern | **天道桌游版** |
|------|----------|-------------|---------------|
| DM/主持人 | 真人（稀缺） | 无 | **天道系统** |
| 玩家角色 | 自行创建 | 无 | 自行创建 |
| 玩家数量 | 3-6人 | 1人 | **不限** |
| 世界观 | DM设定 | 预设 | **天道生成** |
| 事件触发 | DM判断 | 无 | **天道适时触发** |
| NPC控制 | DM控制 | AI角色 | **天道统一管理** |
| 社交性 | 多人同屏 | 无 | **多玩家共享** |
| 持续性 | 阶段性 | 单次对话 | **长期存档** |

## 四、核心模块设计

### 4.1 房间系统 (Room Manager)

**房间类型**：
| 类型 | 说明 | 人数限制 |
|------|------|----------|
| `adventure` | 冒险模式 - 传统TRPG | 2-10人 |
| `social` | 社交模式 - 都市/校园 | 2-20人 |
| `battle` | 战斗模式 - 聚焦战斗 | 2-6人 |
| `sandbox` | 沙盒模式 - 自由探索 | 不限 |

**房间状态**：
```python
class Room:
    room_id: str
    name: str
    room_type: str

    # 成员
    players: Dict[str, Player]      # 在线玩家
    max_players: int

    # DM相关
    dm_mode: str                    # "auto"=天道DM, "manual"=真人DM
    world: World                    # 世界状态

    # 状态
    status: str                     # "waiting", "playing", "paused", "ended"
    current_scene: Scene             # 当前场景
    event_queue: List[Event]         # 事件队列

    # 时间
    game_time: datetime             # 游戏内时间
    real_time_start: datetime       # 开始时间
```

### 4.2 玩家系统 (Player)

**玩家数据结构**：
```python
class Player:
    player_id: str
    nickname: str

    # 角色信息
    character: Character            # 玩家扮演的角色
    y_value: int                    # 角色当前Y值
    base_y: int                     # 角色基线Y值

    # 状态
    status: str                     # "online", "away", "offline"
    position: str                   # 当前位置
    inventory: List[Item]           # 背包

    # 心理状态
    psychology: PsychologyProfile    # 复用天道心理引擎
    recent_actions: List[str]       # 最近动作记录

    # 社交
    relationships: Dict[str, int]   # 对其他玩家/NPC的关系度
```

### 4.4 NPC 系统 (NPC Controller)

**核心设计**：每个NPC都是独立的天道心理实体

```python
class NPC:
    npc_id: str
    name: str

    # 天道心理引擎
    psychology: PsychologyProfile   # Y值、MBTI、记忆、动机

    # NPC特性
    role: str                      # "merchant", "guard", "quest_giver"...
    disposition: str                # "friendly", "hostile", "neutral"
    dialogue_style: str            # 说话风格

    # 状态
    location: str
    current_goal: str              # 当前目标
    awareness_level: str            # "ignorant", "suspicious", "aware"

    # 关系
    relationships: Dict[str, int]  # 对玩家的关系
```

**NPC行为生成**：
```
每回合天道系统为每个活跃NPC计算：
1. 当前心理状态 (基于Y值)
2. 最高优先级本能
3. 表层/深层动机
4. 选择行为类型
5. 生成具体行为/对话
6. 验证行为合理性
7. 输出并记录
```

### 4.5 事件触发器 (Event Trigger)

**触发类型**：

| 类型 | 触发条件 | 示例 |
|------|----------|------|
| `time` | 游戏内时间到达 | 夜幕降临，怪物出现 |
| `location` | 玩家进入某地 | 踏入森林，遭遇野兽 |
| `interaction` | 玩家与NPC交互 | 与商人对话，触发交易事件 |
| `condition` | 满足特定条件 | 收集齐钥匙，打开大门 |
| `random` | 随机概率 | 路上发现宝藏 |
| `story` | 剧情线推进 | 完成前置任务，解锁主线 |
| `player_action` | 玩家特定动作 | 战斗、偷窃、对话等 |

**事件结构**：
```python
class Event:
    event_id: str
    title: str

    type: str                      # 事件类型
    urgency: str                   # "low", "medium", "high", "critical"

    # 触发条件
    trigger: TriggerCondition

    # 内容
    description: str              # 事件描述
    choices: List[Choice]          # 玩家选项

    # 效果
    effects: List[Effect]          # 事件效果
    consequences: List[Consequence] # 后续后果

    # 状态
    status: str                   # "pending", "active", "completed", "failed"
```

### 4.6 世界管理器 (World Manager)

**世界状态**：
```python
class World:
    world_id: str
    name: str
    type: str                      # "fantasy", "urban", "sci_fi"

    # 地理
    locations: Dict[str, Location]
    current_location: str         # 当前主线位置

    # 势力
    factions: Dict[str, Faction]

    # 时间
    time_system: TimeSystem
    game_time: datetime
    time_multiplier: float         # 游戏时间流速

    # 全局状态
    global_events: List[str]       # 全局进行中的事件
    world_state: Dict[str, Any]     # 各种世界状态变量

    # 剧情进度
    main_quest: Quest
    side_quests: List[Quest]
    completed_quests: List[str]
```

## 五、游戏流程

### 5.1 创建房间流程

```
玩家A (DM发起者)
    ↓
[创建房间]
  - 选择世界类型 (都市/玄幻/科幻/自定义)
  - 设置房间名称
  - 选择DM模式 (天道自动DM / 未来支持真人DM)
  - 设置人数上限
    ↓
天道系统生成世界
  - 生成世界观
  - 初始化主要地点
  - 生成初始NPC
  - 生成首个事件
    ↓
房间创建成功
    ↓
分享房间码给其他玩家
```

### 5.2 加入房间流程

```
玩家B/C/D...
    ↓
[输入房间码] 或 [从房间列表选择]
    ↓
[创建角色]
  - 输入角色名称
  - 选择/随机MBTI
  - 填写角色背景
  - 设置基础属性
    ↓
天道系统初始化角色心理档案
    ↓
进入房间，开始游戏
```

## 七、与单机版的区别

| 维度 | 天道独立版 (单机) | 天道桌游版 (多人对战) |
|------|-----------------|---------------------|
| **使用场景** | 个人娱乐、创作辅助 | 多人社交、桌游 |
| **用户数量** | 1人 | N人 (2+) |
| **DM角色** | 无 | 天道担任DM |
| **交互模式** | 玩家↔AI角色 | 玩家↔天道(DM)↔世界 |
| **玩家角色** | 扮演AI设定角色 | 扮演自己创建的角色 |
| **服务器** | 可选本地 | 必须远程服务 |
| **实时性** | 非实时 | 准实时 (消息流) |
| **社交性** | 无 | 多玩家同屏 |
| **技术架构** | 单机 + Web UI | 客户端-服务器架构 |
| **目标用户** | 个人用户 | 小团体、桌游爱好者 |
| **部署位置** | 本地电脑 | 局域网/云服务器 |
| **客户端** | 电脑浏览器 | 手机(Termux)/电脑 |

**核心差异**：单机版是"创作工具"，桌游版是"社交游戏"

## 十二、风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 网络延迟 | 体验下降 | 本地优先，异步同步 |

| 手机性能 | 卡顿 | 精简依赖，CLI优先 |
| 服务器稳定性 | 游戏中断 | 异常捕获，自动恢复 |
